# Security Policy

## Supported Versions

This project is currently under development. Only the latest version is supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through GitHub by contacting the repository owner.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Any relevant screenshots or error messages.

Please do not publicly disclose security vulnerabilities until they have been reviewed.

You can expect an initial response within 7 days.

If the vulnerability is accepted, an appropriate fix will be developed and included in a future update. If it is declined, an explanation will be provided.

## Security Considerations

- User input should be validated before processing.
- Sensitive information and credentials must not be committed to the repository.
- Dependencies should be kept up to date.
- HTTPS should be used in production environments.

This project is intended for educational purposes.
