# Task Manager API

A simple REST API built with JavaScript and Express to demonstrate software testing and DevOps practices.

## Technologies

- Node.js
- Express
- Jest
- Supertest

## Running the project

Install dependencies with `npm install`.

Run the API using `npm start`.

Run tests using `npm test`.

Generate test coverage using `npm run test:coverage`.

## Branching strategy

The `main` branch contains stable code. Changes are developed on short-lived feature or test branches. Each change is committed separately and merged into `main` through a pull request linked to a GitHub issue. Tests are run before merging.
